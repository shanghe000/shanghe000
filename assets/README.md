# Profile artwork

`header.svg` is a self-contained animated vector banner: a quiet wordmark and
one slowly turning Möbius ribbon. It has no scripts, remote fonts or external
image service. The reduced-motion composition is static.

To rebuild, install `fonttools==4.68.0` and run `python scripts/build_header.py`.
The wordmark and tagline are outlined from Space Grotesk, by Florian Karsten,
distributed under the [SIL Open Font License](fonts/OFL.txt).
Font source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk).

The rest of the artwork is covered by this repository's MIT license.
