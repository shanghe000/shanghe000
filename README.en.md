## Selected work

### [Ontology Workbench](https://github.com/shanghe000/ontology-workbench)

A knowledge graph workbench for tracing metrics to their source documents. Weighted evidence traversal, transactional review, workspace-scoped MCP, and optional DeepSeek drafting.

[Run the example](https://github.com/shanghe000/ontology-workbench/blob/main/README.en.md#run-the-example) · [Architecture](https://github.com/shanghe000/ontology-workbench/blob/main/docs/ARCHITECTURE.md) · [MCP example](https://github.com/shanghe000/ontology-workbench/blob/main/docs/LOCAL_ACCESS.md)

### [Tide Lens](https://github.com/shanghe000/tide-lens-harness)

A derivatives research workbench for DeepSeek Harness: multi-exchange data integration, position reconstruction, order-book replay, and field-level evidence for agent-assisted analysis.

[Project](https://github.com/shanghe000/tide-lens-harness) · [Data coverage and methodology](https://github.com/shanghe000/tide-lens-harness/blob/main/docs/coverage.md) · [Downloads](https://github.com/shanghe000/tide-lens-harness/releases)

### [Codex Research Workspace](https://github.com/shanghe000/auto_trade_workspace_for_codex)

Market-data collection, normalized snapshots, read-only demo-account observation, and strategy-governance design. Explores the boundary between agent orchestration and deterministic tools. Experimental; live execution is not enabled.

[Architecture](https://github.com/shanghe000/auto_trade_workspace_for_codex/blob/main/docs/architecture.md) · [Strategy governance](https://github.com/shanghe000/auto_trade_workspace_for_codex/blob/main/docs/strategy-governance.md)

### [Job Filter](https://github.com/shanghe000/job_filter)

A local-first desktop and command-line tool for Chinese civil-service job spreadsheets. It preserves the source file and provides synthetic examples, clear workbook limits, tests, and desktop packages. MIT licensed.

[English guide](https://github.com/shanghe000/job_filter/blob/main/README.en.md) · [Downloads](https://github.com/shanghe000/job_filter/releases) · [Examples](https://github.com/shanghe000/job_filter/tree/main/examples)

### [Open Source Starter](https://github.com/shanghe000/open-source-starter)

A lightweight starting point for consistent project documentation, contribution workflows, repository checks, and draft releases. Project-specific tests and builds remain each project's responsibility.

[Use the template](https://github.com/shanghe000/open-source-starter/generate)

## Working principles

Start with a useful example. State the limits. Verify important behavior. Ship in small steps. Listen to concrete feedback.

Questions and contributions are welcome through the relevant repository's Issues. Forks are learning references and upstream work, not original projects of mine.
