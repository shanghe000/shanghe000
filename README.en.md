## Selected work

### [Job Filter](https://github.com/shanghe000/job_filter)

A local-first desktop and command-line tool for Chinese civil-service job spreadsheets. It preserves the source file and provides synthetic examples, clear workbook limits, tests, and desktop packages. MIT licensed.

[English guide](https://github.com/shanghe000/job_filter/blob/main/README.en.md) · [Downloads](https://github.com/shanghe000/job_filter/releases) · [Examples](https://github.com/shanghe000/job_filter/tree/main/examples)

### [Open Source Starter](https://github.com/shanghe000/open-source-starter)

A lightweight starting point for consistent project documentation, contribution workflows, repository checks, and draft releases. Project-specific tests and builds remain each project's responsibility.

## Working principles

Start with a useful example. State the limits. Verify important behavior. Ship in small steps. Listen to concrete feedback.

Questions and contributions are welcome through the relevant repository's Issues. Forks are learning references and upstream work, not original projects of mine.
